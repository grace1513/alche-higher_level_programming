# JavaScript Web Scraping

## Introduction

This project focuses on web scraping and file handling using **JavaScript** and **Node.js**. It demonstrates how to interact with web APIs, retrieve and process data, read from and write to files, and handle asynchronous operations using callbacks. Throughout the project, the built-in **File System (fs)** module and the **request** module are used to perform file operations and HTTP requests, providing practical experience with working with external resources and JSON data in Node.js.
