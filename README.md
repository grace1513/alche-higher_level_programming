Higher Level Programming 🐍


📌 Description

This repository contains projects and exercises related to higher-level programming using Python and shell scripting. It focuses on learning programming fundamentals such as scripting, automation, and writing clean, standardized code in a Linux environment.

The projects are designed to build strong foundations in:

Python programming
Shell scripting
Command-line usage
Code style and best practices

⚙️ Environment

Ubuntu 20.04 LTS
Python 3.8.5
Bash shell

📁 Repository Structure

Each project is organized into separate directories, each containing its own scripts and documentation.
