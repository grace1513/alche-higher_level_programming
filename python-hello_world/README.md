# Python Hello World

## Description
Introduction to Python programming covering:
- Running Python scripts
- Printing with f-strings
- Float formatting
- String manipulation
- String slicing

## Files
- 0-run: Shell script that runs a Python script
- 1-run_inline: Shell script that runs Python inline
- 2-print.py: Prints a string
- 3-print_number.py: Prints integer using f-string
- 4-print_float.py: Prints float with precision
- 5-print_string.py: Prints a string multiple times
- 6-concat.py: Concatenates two strings
- 7-edges.py: Prints edges of a string using slicing
- 8-concat_edges.py: Concatenates edges of a string
- 9-easter_egg.py: Prints the Zen of Python
