# Python - Imports & Modules

## Project Overview

This project introduces the fundamentals of Python modules, imports, and command-line arguments. It is designed to help learners understand how Python programs can be organized into reusable, maintainable, and modular code. By working through these tasks, you will discover why Python is considered an excellent programming language for beginners and professionals alike.

## Requirements

### General

* Allowed editors: `vi`, `vim`, `emacs`
* All files will be interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8.5)
* All files must end with a new line
* The first line of all Python files must be exactly:

  ```python
  #!/usr/bin/python3
  ```
* A `README.md` file at the root of the project folder is mandatory
* Your code must follow `pycodestyle` (version 2.7.*)
* All files must be executable
* The length of your files will be tested using `wc`

## Key Concepts Covered

* Python modules and code reusability
* Importing specific functions and entire modules
* Using aliases during import
* Exploring module contents with `dir()`
* The purpose of `if __name__ == "__main__":`
* Handling command-line arguments with `sys.argv`

## Why This Project Matters

Understanding imports and modules is a major step toward writing professional Python code. Instead of placing all your code in one file, you can split it into logical, reusable components. This improves readability, simplifies debugging, and makes your programs easier to maintain and scale.

Additionally, learning how to control script execution and accept command-line arguments prepares you for building more interactive and flexible applications.
