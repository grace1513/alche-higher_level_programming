# Python Control Flow Basics

##  Overview

This project focuses on practicing the fundamentals of Python control flow, including loops, conditionals, and basic operations. It helps build a strong foundation for writing logical and efficient Python programs.

---

##  Learning Objectives

* Understand how `for` loops work with `range()`
* Use conditional statements (`if`, `elif`, `else`)
* Apply logical operators (`and`, `or`)
* Work with arithmetic operations
* Format output using `print()`

---

##  Concepts Covered

###  Loops

* Iteration using `for`
* Using `range(start, stop, step)`
* Controlling loop output

###  Conditionals

* Decision-making with `if`, `elif`, `else`
* Nested conditions
* Boolean logic

###  Operators

* Arithmetic: `+`, `-`, `*`, `/`, `%`
* Comparison: `==`, `<`, `>`
* Logical: `and`, `or`

---

##  Key Takeaways

* `range()` excludes the stop value
* `%` is useful for checking even and odd numbers
* `and` requires all conditions to be true
* `or` requires at least one condition to be true
* Proper indentation is essential in Python

---

##  Conclusion

This project strengthens core Python concepts and builds the foundation needed for more advanced topics like functions, data structures, and object-oriented programming.
