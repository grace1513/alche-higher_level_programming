# Python Network 1

## Introduction

This project focuses on interacting with web resources using Python. It introduces the use of the `urllib` and `requests` libraries to send HTTP requests, retrieve and decode responses, and work with JSON data from external services. Through these exercises, the project aims to strengthen understanding of client-server communication and the fundamentals of handling web resources in Python.

## Conclusion

Overall, this project provides practical experience in making HTTP requests and manipulating data obtained from external services. It highlights the simplicity and effectiveness of Python's networking libraries and reinforces good programming practices such as proper documentation, code organization, and adherence to PEP 8 standards.
