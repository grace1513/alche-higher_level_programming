# HTTP, URLs and cURL Project

## Introduction

This project focuses on understanding the fundamentals of web communication using HTTP, URLs, cookies, and cURL. It explores how browsers and servers communicate through requests and responses, how URLs are structured, and how data can be transferred across the internet. The project also introduces the use of Bash and Python scripts to interact with web servers and handle HTTP requests.

## Conclusion

Through this project, I gained a better understanding of how the web works at the application level. I learned how HTTP requests and responses function, how URLs are structured, and how tools like cURL can be used to communicate with servers. This project also strengthened my scripting and documentation skills while improving my understanding of client-server communication.
